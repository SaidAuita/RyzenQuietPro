## Текущая итерация: v4.02
- [x] **Исправление скрытия окна**: окно больше никогда не скрывается автоматически при потере фокуса или переключении на другие программы (отключен вызов `Hide()` в `Deactivate`). Окно видно всегда и закрывается только по кнопке закрыть `[X]`.
- [x] **Мониторинг дискового ввода-вывода (Process Disk I/O)**: в `ProcessMonitor.cs` внедрено считывание системных счетчиков `ReadTransferCount` (offset 192) и `WriteTransferCount` (offset 200) ядра Windows через `ntdll.dll!NtQuerySystemInformation`. Точный расчет дельты байт (MB/s Read/Write) без нагрузки на CPU.
- [x] **Интерактивное раскрытие процессов диска**: по клику на любой диск в легенде `DiskLegendPanel` разворачивается плашка топ-процессов дискового ввода-вывода с иконками, именами процессов, скоростями чтения/записи (MB/s) и кнопкой быстрого перехода в Монитор ресурсов Windows (`resmon.exe /res disk`).
- [x] **Динамическое изменение размера окна**: окно плавно расширяется на 74px при открытии карточки процессов выбранного диска и сжимается при закрытии, гарантируя отсутствие полос прокрутки.
- [x] **Обновление локализаций и версий**: обновлены словари `Localization.cs`, манифесты и заголовки до `v4.02`. Сборка тестовых бинарников.
