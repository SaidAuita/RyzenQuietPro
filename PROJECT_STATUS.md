## Текущая итерация: v4.04
- [x] **Множественные секундомеры с индивидуальными цветами**:
  - Добавлена поддержка создания нескольких независимых секундомеров (`StopwatchProfile` / `StopwatchItem`), каждый со своим именем, активным таймером и выбранным цветом из неоновой палитры (Изумрудный, Янтарный, Небесно-голубой, Фиолетовый, Розовый, Оранжевый, Бирюзовый, Белый).
  - На главной панели (`DashboardPro.cs`) каждый секундомер отображает цифры в индивидуальном цвете со свечением при работе, а под временем выводится бейдж отслеживаемого приложения (`🎯 [Приложение]` или `🌐 Любая программа`).
- [x] **Группировка процессов приложений (как в DropFile)**:
  - В `ProcessMonitor.cs` реализован сбор запущенных приложений `ProcessAppGroup` и метод `GetRunningAppGroups()` с объединением множественных PID одного исполняемого файла (например, 15+ процессов `chrome.exe`) в единую группу с суммированием CPU% и RAM, определением понятного названия приложения и извлечением иконки.
  - Постоянный расчет CPU% для отслеживаемых приложений в `Sample()` даже при скрытом виджете топ-процессов.
- [x] **Запуск секундомера по мощности для определенной программы**:
  - Если в секундомере указано целевое приложение (`TargetExe`), секундомер запускается по мощности только при одновременном выполнении условий: системная мощность выше порога старта И целевое приложение активно производит нагрузку (`appCpu >= 0.5%`).
  - Остановка секундомера происходит при падении мощности ниже порога автостопа ИЛИ при закрытии / уходе в глубокий простой целевой программы (с учетом гистерезиса).
  - Глобальные пороги мощности (Ватты старта, Ватты остановки, гистерезис, источник CPU/GPU/Total/Max) остаются общими.
- [x] **Интерфейс управления и диалоги выбора**:
  - Создан диалог `ProcessSelectDialog.cs` с поиском, иконками, группировкой и метриками CPU/RAM в реальном времени.
  - Создан диалог `StopwatchEditDialog.cs` с настройкой имени, палитрой цветов и селектором программы.
  - В `SettingsForm.cs` добавлен список секундомеров с возможностью добавления, редактирования и удаления.
  - На дашборде добавлена кнопка `[+]` для быстрого добавления секундомера и динамический пересчет высоты карточки секундомеров.
- [x] **Доработки секундомера и графика CPU (v4.04)**:
  - Выравнивание шрифта названия приложения под секундомером по размеру шрифта информации о CPU (`Segoe UI 8.0f`), цвет голубой (`#38BDF8`), устранены сбойные глифы `🔲`.
  - Отображение чистого имени процесса, если имя секундомера не задано (без подстановки "Stopwatch" / "Секундомер").
  - Выбор произвольного кастомного цвета секундомера через диалог `ColorDialog` (кнопка `🎨 Свой цвет...`).
  - Отрисовка цветной кривой нагрузки приложения на графике CPU при запуске секундомера (индивидуальный чекбокс в настройках секундомера).
  - Масштабирование графика нагрузки CPU: предустановки масштаба `1x` (100%), `2x` (50%), `4x` (25%), `6x` (16.7%), `8x` (12.5%) и `Auto` (динамический подбор по пику) в Настройках, а также интерактивный бейдж `[ x4 ]` в правом верхнем углу графика CPU на дашборде с циклическим переключением масштаба в один клик.
  - Постоянное сохранение кривой нагрузки секундомера: график отслеживаемого приложения не исчезает при остановке/паузе секундомера, а продолжает плавно прокручиваться во временном окне 60 секунд, позволяя наглядно анализировать прошедшую операцию. Очищается только при явном сбросе таймера.
  - Исправление отображения номера версии в шапке окна (`_lblTitle`) и во всех словарях локализации на `v4.04`.
- [x] **Индивидуальный масштаб и кнопки графиков секундомеров прямо в GUI**:
  - На дашборде на каждой строке секундомера добавлена интерактивная кнопка масштаба `[📈 Auto]` / `[📈 x2]` / `[📈 x4]` / `[📈 x8]` / `[📈 x16]` / `[📈 1x]` / `[📈 Off]` с подсветкой в акцентный цвет секундомера для переключения в один клик.
  - **Независимый масштаб от общего графика CPU**: в режиме `Auto` кривая нагрузки приложения (например, 3.0% в Illustrator при векторизации/рендере) нормализуется под собственный пик, заполняя ~75% высоты графика и отчетливо визуализируя нагрузку сразу при запуске секундомера.
  - На конце цветной кривой нагрузки на графике CPU отображается живой маркер и бейдж с текущим процентом (например, `● 3.0%`).
  - В диалоге редактирования секундомера (`StopwatchEditDialog`) и в списке секундомеров в `SettingsForm` добавлены селекторы и индикаторы масштаба.
- [x] **Устранение зависания метрик процессов при переключении масштаба**:
  - В `HardwareMonitor.Sample()` добавлен неблокирующий guard реентерабельности (`Interlocked.CompareExchange`) для предотвращения одновременного выполнения тиков таймера из разных потоков ThreadPool при задержках или операциях ввода-вывода.
  - В `ProcessMonitor.Sample()` внедрен `Monitor.TryEnter(_sampleLock)`, а внутренние словари baseline-времен заменяются на свежие экземпляры при любых сбоях, предотвращая исключения гонки коллекций (`Operations that change non-concurrent collections must have exclusive access`).
  - Кэш метаданных процессов переведен на потокобезопасный `ConcurrentDictionary`, устранены гонки между UI-потоком диалогов и фоновым потоком мониторинга.
  - Исправлено обрезание знака `%` для двузначных процентов CPU (например, `13.8%`) в виджете топ-процессов на дашборде.
