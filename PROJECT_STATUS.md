## Текущая итерация: v4.05
- [x] **Автоматическое расписание работы HDD без сна (HDD Awake Schedule)**:
  - Создан менеджер расписания `HddScheduleManager.cs`, выполняющий проверку времени в основном цикле `HardwareMonitor.Sample()` каждую секунду.
  - Поддержка настройки диапазона рабочих часов (по умолчанию с 07:00 до 17:00, с понедельника по пятницу `HddWorkDaysOnly`).
  - При входе в рабочее время через `PowerPlanManager.SetDiskIdleTimeout(0)` тайм-аут сна дисков в схеме электропитания Windows автоматически выставляется в `0` (никогда не усыплять) параллельно через `powercfg /change disk-timeout-ac 0` и через установку GUID-индекса `SUB_DISK` `DISKIDLE` с немедленной реактивацией `SCHEME_CURRENT`.
  - При входе в рабочее время инициируется параллельная фоновая раскрутка всех подключенных HDD (`WakeUpAllHddsAsync()`).
  - В нерабочие часы (вечер, ночь, выходные дни) тайм-аут сна дисков автоматически возвращается к значению энергосбережения `HddOffHoursTimeoutMinutes` (предустановки: 10, 15, 20, 30, 60 минут, по умолчанию 20 мин).
- [x] **Импульс бодрствования Keep-Alive (защита от встроенных APM-прошивок)**:
  - Некоторые современные HDD (Western Digital Red/Purple, Toshiba) имеют агрессивные внутренние тайм-ауты APM (Advanced Power Management) и паркуют головки / глушат шпиндель даже при значении Windows timeout = 0.
  - Реализован легковесный фоновый импульс каждые 90 секунд: безопасное чтение свободного пространства томов `DriveInfo.TotalFreeSpace` и корневых каталогов физических дисков без записи на диск, поддерживающий шпиндели активными.
- [x] **Мгновенная ручная раскрутка всех HDD (`⚡ Раскрутить диски`)**:
  - Кнопка немедленной раскрутки дисков в настройках с асинхронным выполнением в фоне и цветовой индикацией статуса (`Раскрутка...` / `Все диски активны`).
- [x] **Полная мультиязычность (8 языков)**:
