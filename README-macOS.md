# ⚡ RyzenQuiet PRO for macOS (v3.0)

**Акустический оптимизатор и аппаратный монитор для macOS (10.15 Catalina и новее), оптимизированный для ThinkPad x230 (Хакинтош), AMD/Intel Hackintosh и виртуальных машин.**

---

## 🎯 Поддерживаемые конфигурации
* **macOS 10.15 Catalina** (и выше: Big Sur, Monterey, Ventura, Sonoma).
* **Архитектура:** `osx-x64` (Intel 64-bit Core i3/i5/i7, AMD Ryzen Hackintosh, виртуальные машины VMware/VirtualBox/Proxmox).
* **Тестовый стенд:** ThinkPad x230 (Intel Core i5-3320M / i7-3520M, Intel HD Graphics 4000, VirtualSMC / FakeSMC).
* **Автономность:** Исполняемый файл полностью самодостаточен (**Self-Contained Single-File Mach-O 64-bit**). **Не требует установки .NET SDK на macOS!**

---

## 🚀 Быстрый запуск на macOS

### Способ 1: Двойной клик в Finder (через .command)
1. Скопируйте папку `build/mac` на ваш Mac (на x230 или в виртуальную машину).
2. Сделайте двойной клик на файле **`RyzenQuiet-Mac.command`**.
   *(При первом открытии macOS может спросить подтверждение запуска; откройте через Правый клик -> Открыть).*

### Способ 2: Запуск через Terminal
```bash
cd /путь/к/папке/build/mac
chmod +x ./RyzenQuiet.Mac
./RyzenQuiet.Mac
```

## ✨ Ключевые возможности на macOS

### 1. 🌿 Режим Тишины (Silent Mode) vs ⚡ Режим Производительности (Boost)
* **На ThinkPad x230 / Intel Mac:**
  * **Режим Silent (99%):** Фиксирует тактовую частоту процессора на базовом уровне (2.60 ГГц), отключая перегревающий процессор агрессивный Intel Turbo Boost. Напряжение падает, температура снижается на 15–25°C, а шумный вентилятор x230 мгновенно сбавляет обороты до бесшумных или полностью останавливается!
  * **Режим Boost (100%):** Включает максимальный турбо-буст до 3.3–3.6 ГГц для тяжелых компиляций и вычислений.
* **На AMD Ryzen Hackintosh / VM:**
  * Управляет профилем энергопотребления процессора.

### 2. 📊 Полная аппаратная телеметрия
* 🟢 **CPU:**
  * Точная модель процессора (`machdep.cpu.brand_string`).
  * Текущая частота и число потоков/ядер (на x230: `2C/4T`, до 16/32/64T в виртуалках).
  * 60-секундный спарклайн-график нагрузки.
  * Тепловая карта загрузки всех ядер `[T1: 24%] [T2: 15%] ...`
  * Список Top-5 самых прожорливых процессов (PID, Имя, CPU%, RAM%).
* 🔵 **RAM:**
  * Спецификация памяти (`DDR3/1600` на x230) и точный объем.
  * Живой опрос ядра через Mach `host_statistics64(HOST_VM_INFO64)` с разделением на Active, Wired, Compressed и Free.
* 🟣 **GPU / VRAM:**
  * Обнаружение видеоадаптера (`Intel HD Graphics 4000`, `VMware SVGA`, `AMD Radeon`).
  * Объем выделенной видеопамяти (например, `Shared 1.5 GB`).
* 🩵 **DISK:**
  * Активный системный накопитель `/ (Macintosh HD)`.
  * Скорость чтения и записи в МБ/с (Read / Write MB/s).
* ❄️ **FANS:**
  * Опрос скорости кулера через AppleSMC / VirtualSMC / FakeSMC.
  * Два режима визуализации (переключение клавишей `[F]`):
    * **График:** 60-секундная динамика RPM.
    * **Иконки (Impeller):** Карточки кулеров с лопастями по скоростям (3 лопасти при 0 RPM, 4 в тихом режиме < 1200 RPM, 7 в среднем режиме, 11 в турбо-режиме > 2200 RPM).
  * **Демо-режим (`[D]`):** Встроенная симуляция 5 вентиляторов для тестирования в виртуальных машинах, где нет физических датчиков кулера.

## ⌨️ Управление горячими клавишами в консоли

| Клавиша | Действие |
|:---:|---|
| **`[S]`** или **`[Q]`** | Активировать **Тихий режим (Silent Mode)** |
| **`[B]`** | Активировать **Режим Boost (Turbo Mode)** |
| **`[F]`** | Переключить режим отображения кулеров (**График ↔ Иконки**) |
| **`[D]`** | Включить/выключить **Демо-режим кулеров** |
| **`[X]`** или **`[Esc]`** | Выход из программы |

* Полноценный киберпанк-интерфейс с живыми векторными графиками HTML5 Canvas.

* Кнопки переключения режимов `Silent` и `Boost` в один клик.

## 🛠️ Сборка из исходников

### На Windows:
Запустите скрипт:
```cmd
build-mac.bat
```

### На macOS (если установлен .NET 8 SDK):
```bash
dotnet publish RyzenQuiet.Mac/RyzenQuiet.Mac.csproj -c Release -r osx-x64 --self-contained true -o build/mac
```
